# SQL - Data Definition Language (DDL)

## What is DDL?
DDL stands for Data Definition Language. It is used to define and modify the structure of database objects, such as tables.

## 1. CREATE
Used to create a new database or table.

Example:
CREATE TABLE Students (
    StudentID INT,
    Name VARCHAR(50),
    Age INT
);

## 2. ALTER
Used to modify the structure of an existing table.

Example:
ALTER TABLE Students ADD Email VARCHAR(100);

## 3. DROP
Used to permanently remove a database object, such as a table.

Example:
DROP TABLE Students;

## 4. TRUNCATE
Used to remove all rows from a table while keeping its structure.

Example:
TRUNCATE TABLE Students;

## 5. RENAME
Used to rename a database object. The exact syntax depends on the database system.

Example (MySQL):
RENAME TABLE Students TO StudentDetails;

## Important Points
- DDL stands for Data Definition Language.
- CREATE creates database objects.
- ALTER modifies the structure of database objects.
- DROP removes database objects.
- TRUNCATE removes all rows but keeps the table structure.
- RENAME changes the name of a database object.
- DDL commands generally cause implicit commits in many database systems, but behavior varies by database.

DML (Data Manipulation Language) – Short Notes
Definition: DML stands for Data Manipulation Language. It is used to retrieve, insert, update, and delete data in database tables.
1. INSERT
Used to add new records (rows) to a table.

Syntax:
INSERT INTO Student (ID, Name)
VALUES (1, 'Ravi');

2. UPDATE
Used to modify existing records in a table.

Syntax:
UPDATE Student
SET Name = 'Kiran'
WHERE ID = 1;

3. DELETE
Used to remove specific records from a table.

Syntax:
DELETE FROM Student
WHERE ID = 1;

4. SELECT
Used to retrieve data from a table. It is commonly classified as DQL (Data Query Language), though some learning materials include it under DML.

Syntax:
SELECT * FROM Student;

Quick Revision
Command	Purpose
INSERT	Adds new records
UPDATE	Modifies existing records
DELETE	Removes records
SELECT	Retrieves records


Remember:
- INSERT → Add data
- UPDATE → Change data
- DELETE → Remove data
- SELECT → View data
Important: Always use a WHERE clause with UPDATE and DELETE when you want to affect only specific rows. Without it, the command can modify or delete all rows in the table.
